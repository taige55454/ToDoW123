# ToDoWell 2.5.13

桌面极简待办事项管理工具。原生 C++17 + Direct2D 编写，单文件免安装，常驻桌面右下角。

项目主页: <https://anqilike.github.io/ToDoWell/>

下载: 最新版安装包见 [Releases](https://github.com/anqilike/ToDoWell/releases/latest)（单文件 exe，免安装）。

---

## 🎯 核心功能

### 1. **自然语言解析**
输入示例：`明天 18:00 每天 重要 写报告`
- 自动识别时间：`明天`、`后天`、`下周三`、`每月1号`
- 识别优先级：`!` 或 `重要`
- 识别周期：`每天`、`工作日`、`每周一三五`、`每月1,15号`

### 2. **四象限视图**
- 重要且紧急（红色背景）
- 重要不紧急（绿色背景）
- 紧急不重要（黄色背景）
- 不重要不紧急（灰色背景）

### 3. **周期计划管理**
- 独立管理周期计划蓝图
- 自动派发实例到主列表
- 支持每日/工作日/每周/每月

### 4. **专注森林**
- 番茄钟计时（默认 25 分钟）
- 成长动画：种子 → 幼苗 → 树木
- 完成后自动标记关联任务
- 森林统计与历史记录

### 5. **智能延期**
- 右键延后一天，自动隐藏到明天
- 逾期任务红色警示
- 记录原始截止日期
